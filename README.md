# Digital Product Research Dashboard

A personal research tool for exploring selected digital-product niches using public listing data from online marketplaces.

## Planned functionality

- Retrieve limited samples of public listings for configured keywords through marketplace APIs.
- Save structured results in local files.
- Display listing titles, prices and links in a private dashboard.
- Check collected data for completeness, duplicates and accuracy.

## Status

Under development. Marketplace API access is pending approval. The implementation is currently maintained privately; this repository provides a public project overview.

## Access and scope

The initial version is for the developer's own use. It is read-only and does not access private buyer data, modify listings, send emails or charge users.

## Disclaimer

This project is independent and is not endorsed or certified by any marketplace platform.
